# Changelog

## 0.1.0

- Initial public release.
- Alamofire ZIP download with progress and cancellation.
- ZIPFoundation extraction with transactional activation.
- Configurable storage directory, limits, timeouts, and fallback color.
- Extensible manifest color tokens.
- Sandbox image loading with 1x, `@2x`, and `@3x` fallback.
- ZIP path, size, manifest, and PNG validation.
